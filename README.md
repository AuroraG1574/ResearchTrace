# 研迹 ResearchTrace

**科研文献的持续追踪、证据整理与综述协作工作台。**

研迹配合 Codex 使用，将论文、阅读卡、个人笔记、原文证据和综述集中保存在本地。研究者确定方向、确认方案并审核结果；Codex 根据任务执行检索、阅读和写作，再通过组件接口写回。

当前发布版本：**v0.7.0 · Windows**。适合配合《科研文献的持续追踪与综述构建》章节开展实践，也可用于建立自己的研究项目。

## 下载与安装

请在本仓库的 **Releases** 页面下载 Windows 安装包及对应 SHA-256 校验文件。安装包包含安装入口、完整程序、源码、使用教程和免责声明。请下载名称含“最终组件包”的 ZIP；GitHub 自动生成的 Source code ZIP 仅打包本仓库的网页文档，不是组件安装包。

1. 将安装包完整解压，不要在压缩包预览窗口中直接运行。
2. 双击 `安装研迹.cmd`，完成后打开桌面“研迹”快捷方式。
3. 阅读[使用教程](使用教程.md)，新建研究项目。

默认安装到当前用户的 `%LOCALAPPDATA%\ResearchTrace`，无需管理员权限。也可把完整 `ResearchTrace` 文件夹放在有写权限的位置，直接运行其中的 `LiteratureDesk.exe`。

首次打开为空白资料库。本仓库和安装包均不包含作者的研究项目、论文附件、个人笔记或账号凭据。

## 主要功能

- **共同明确需求**：从一句研究兴趣开始，与 Codex 讨论并维护长期任务 Spec。
- **追踪与导入文献**：导入 DOI、arXiv 标识、RIS、BibTeX 或 PDF，记录检索范围、筛选理由和覆盖限制。
- **按论文整理笔记**：在文献条目下查看结构化阅读卡与相关笔记，区分个人内容、AI 内容和项目记录。
- **积累可追溯证据**：关联原文摘录、位置、解释及人工核验状态，比较不同研究的条件和结果。
- **共同形成综述方案**：在材料积累后讨论主线、纳入范围和提纲，确认方案后开展写作。
- **审核与修改**：提出具体修改意见，生成交给 Codex 的任务，保留正文、引用清单和版本记录。

文献更新与综述写作分别发起。新增文献不会自动改写已有综述或改变其纳入清单。

## 一次完整的使用流程

建立项目 → 与 Codex 完善长期 Spec → 确认规则 → 检索与更新文献 → 阅读与整理笔记 → 比较证据 → 共同拟定本篇综述方案 → 确认后写作 → 人工审核并迭代 → 导出。

在组件中点击“复制本轮任务”后，需要粘贴到 Codex 并发送。组件负责管理和展示资料，研究任务由 Codex 及实际可用的工具完成。填写周期不代表定时任务已经建立；定时任务需另行创建，并核对真实执行记录。

## 环境与边界

- 已验证环境为 Windows x64；主程序使用 .NET Framework 4.x。macOS 不能直接运行本包；32 位 Windows 和 Windows ARM 尚未完成验证。
- Codex 账户、模型使用权限、网络与文献来源访问需另行准备，本包不含模型额度或数据库订阅。
- 查看、编辑和导入不需要 Python。需要随包科研脚本时，再按教程准备 Python 3.11+ 及相关依赖。
- 随包 Skills 按任务选择，不是每轮必须调用；固定版本来源与许可见安装包内 `ResearchTrace/docs/上游Skills接入流程.md`。
- 发布包未进行商业代码签名。请核对来源和校验值，遵守所在机构的软件管理要求。

## 源码与资料库

安装包内的 `ResearchTrace/src` 保存 Windows 主程序源码，`ResearchTrace/web` 保存工作台页面，`ResearchTrace/tools` 保存按需使用的科研脚本。Windows 上可在组件目录运行 `build.ps1` 编译主程序。修改源码后需要重新生成发布校验清单才能作为新的安装包发布，不应直接使用旧校验清单安装修改后的文件。

项目资料默认位于实际运行目录的 `data` 文件夹，不应上传到公开仓库。更新、迁移或卸载前，等待写入结束并退出组件，再备份整个资料目录。本地保存不表示所有研究步骤离线；在线检索与云端 AI 处理可能向所选服务发送相应内容。
