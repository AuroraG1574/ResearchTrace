# 研迹 ResearchTrace v0.7.0

科研文献持续追踪、阅读笔记、证据比较与人机协作综述工作台。

## 下载哪个文件

打开 [GitHub Releases](https://github.com/AuroraG1574/ResearchTrace/releases)，在最新上传的 v0.7.0 发布说明下选择对应平台的附件：

| 你的电脑 | 只需下载这一份 |
| --- | --- |
| Windows | **ResearchTrace-0.7.0-Windows.zip** |
| Mac：M 系列（含 M4）或 Intel | **ResearchTrace-0.7.0-macOS.zip** |

两个平台产品版本均为 **0.7.0**。Mac 单个压缩包自动选择 Apple silicon 或 Intel 运行环境。GitHub 自动生成的 Source code 不是安装文件。

## 安装与打开

- **Windows：**完整解压 → 双击“安装研迹.cmd” → 双击桌面“研迹”快捷方式 → 小窗“展开科研工作台”。
- **Mac：**完整解压 → 双击“安装研迹.command”，输入 `INSTALL` → 从 `~/Applications` 打开 `ResearchTrace.app` → 小窗“展开科研工作台”。

详细步骤、系统要求和升级说明见 [开始使用](开始使用.md)。安装包内也包含教程。

## 两个平台当前的区别

两者都有桌面小窗。Windows 优先通过 Edge 的独立应用窗口展示工作台，无法找到相应 Edge 程序时使用默认浏览器；Mac 当前直接在默认浏览器中打开完整工作台，尚未提供与 Windows 相同的独立工作台窗口。Mac 的浏览器页面和小窗配合使用，不是故障，也不是云端托管页面；资料默认保存在本机。

截至 2026-11-18，M4 使用者已确认当前 Mac 版能显示小窗，并能在浏览器打开工作台。该确认仅覆盖这两项基础启动结果；菜单栏、隐藏恢复、置顶、PDF、完整研究流程和升级保留资料等仍需逐项验收。Intel 及其他 M 系列尚未取得实机验证结果。

Mac 要求 macOS 15 或更新版本，尚未进行 Developer ID 签名和公证，首次安装可能遇到系统提示。完整差异、已知限制和问题排查见 [Mac安装与验证](Mac安装与验证.md)。Windows 目前已在 x64 环境验证，32 位与 Windows ARM 未完成验证。

## 如何开展研究

建立项目并共同明确长期 Spec → 检索与更新 → 阅读卡与笔记 → 核查证据 → 积累材料后讨论本篇综述方案 → 分节写作 → 审核与迭代 → 导出。

组件负责保存和展示材料；智能体负责用户发起的研究任务。复制任务后需要主动发送给智能体，填写更新周期不等于已建立定时任务。读者须另行准备智能体账号、工具和文献访问权限。
